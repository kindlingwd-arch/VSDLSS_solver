# 1–6 阶求解微内核

## 实现

`tools/generate_small_solve.py` 确定性生成 `src/vsdlss_small_solve.inc`。六个函数的三角前代/回代均显式展开；前代外部行贡献按固定宽度展开，回代每列的外部内积仍沿外部行循环（长度运行时确定）。保留逐项相减次序和主元检查。已有 1–6 项面板内积展开继续使用。

调用时只分派一次；大外部行工作量且请求多线程时使用原有通用并行路径。当前内核不分配堆内存，不引入 BLAS，不改变公开 API。通用求解内核保留为内部对照入口。生成文件有明确构建依赖；不是依赖优化器特化的占位入口。

## 验证和范围

`make test-small` 覆盖全部宽度、前后代、0–64 外部行、非连续索引和非零起始位置；对零主元、NaN、Inf 验证状态及修改后的向量逐位一致。完整 M1/M3/M4 回归负责因子重构、残差、用户输出事务保护及多线程路径。逐位一致仅指相同构建下与本项目通用核比较，不代表原版二进制一致。

## 性能

OpenMP 构建，默认单线程，每组 50000 次调用、16 外部行，交替前后代；每次复制相同工作向量。五轮中位数，原始数据见 small-kernel-runs.txt。通用核包含串行 OpenMP 区域开销，下面收益不能归因于展开本身，也不能外推整体求解器加速。未证明所有尺寸均有收益；大型任务保留并行回退。
