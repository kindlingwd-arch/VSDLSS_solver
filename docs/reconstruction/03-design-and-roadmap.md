# 重建设计草案与阶段验收

状态：M1 已获用户确认并按“单一新实现”修订。旧兼容层和占位实现不再属于交付范围。

## 2026-09-08 范围修订

用户确认：不再追踪旧程序壳层的问题，也不保留同名但语义未恢复的 catalog、MLD、块结构和 ABI 占位代码。`reference/` 只作为反编译证据保存；新求解器忠实采用证据能够支持的流程原理，但不伪装成逐行或 ABI 兼容实现。

## 路线选择

| 路线 | 优点 | 代价/限制 |
|---|---|---|
| 逐行修复 Ghidra 输出 | 最接近原版内存和文件行为 | 依赖原始汇编、常量、完整调用闭包及运行环境，暂不适合先建立可信求解器 |
| 基于证据分阶段重建（推荐） | 复用现有数学核心，先保证正确性；逐步补回排序和分块 | 首阶段只承诺 SPD 数学行为，不承诺原版 ABI 或性能 |
| 包装成熟外部求解库 | 快速建立独立参考与生产基线 | 不能替代恢复原版原理；增加依赖且偏离自主重建目标 |

建议第二条，必要时用第三条作独立数值参考。对用户已有代码优先审计、加固和明确弃用边界，而不是另起一套同名空壳。

## 第一阶段：可信 SPD 内存求解闭环

首阶段覆盖实数 double、方阵、对称正定、自然序/RCM、同一因子多次求解；索引用 int64_t。暂不宣称一般 LU、不定 LDLᵀ、GPU、并行、原版块文件或 37 参数接口兼容。

### 分层及文件责任

| 层 | 预定位置 | 职责 |
|---|---|---|
| 稳定公共接口 | `include/vsdlss.h` | 明确索引、置换、错误及所有权；保留可兼容的已有入口 |
| 矩阵输入与验证 | `src/vsdlss_matrix.c`（新） | 检查 CSC，复制/排序/合并重复项，计算对称 SpMV、残差 |
| 排序 | `src/vsdlss_ordering.c`（从核心拆出） | 自然序、修复 RCM、双射验证；不依赖旧 MLD 全局状态 |
| 数学核心 | `src/vsdlss.c` | 消元树、符号计数、数值分解与三角代入，加固失败处理 |
| 文件适配 | `src/vsdlss_io.c`（新） | 单独处理 `.hdr/.mat*` 和 RHS，检查长度、坐标及输出失败 |
| 命令行入口 | `src/main_vsdlss.c` | 只调用稳定 M1 API；不经过旧 catalog 或伪 ABI |
| 测试 | `test/` | 独立参考、小矩阵、非法输入、排序性质和文件回归 |

最终拆分和具体函数签名在设计确认后写入逐任务实现计划，不将此路线图冒充详细编码任务。

### 接口契约

- 输入上三角 CSC；索引 0-based。输入可未排序且可重复，但进入数值核心前必须规范化；重复项求和。
- 超出上三角、非方阵、非法列指针、越界行号、NaN/Inf 明确报错；不能静默丢弃。
- 首阶段 n≥1；空矩阵明确拒绝。所有分配大小先检查负数与乘法溢出。
- `q[new]=old`、`pinv[old]=new`，对矩阵、RHS、输出严格使用同一约定。
- 统一旧数字 order：0 为默认 RCM，1 为 RCM，2 为自然序，其他值报错；这是重建 API 约定，不是原版参数恢复结果。
- 因子构造不修改输入 A；因子拥有自己的存储和置换。分解结束后可释放 A，但残差计算仍需调用方保留 A。
- 同一因子可对多个 RHS 顺序求解；不能隐式重新分解。首阶段不承诺并发访问安全。
- 新增可区分的状态：成功、非法输入、内存不足、非正定、非有限数、I/O 失败、不支持。旧 bool/NULL API 由适配层保持。
- 原地求解失败时保留原 RHS；先在临时缓冲计算，成功后写回。
- `.rhs` 不存在的演示行为必须有明确模式标识；已存在但长度错误必须报错。磁盘端序和宽度在适配层说明，不能直接假定本机 long 等于文件整数。
- 因子与输入不可用裸 32 位整数保存指针；旧原始 ABI 恢复是独立任务。

### 最小验收矩阵

| 测试组 | 输入/构造 | 必须验证 |
|---|---|---|
| 精确小例 | A=[[4,1],[1,3]]，x=[2,-1]，b=[7,-1] | 两种排序正确；因子重构正确 |
| 非恒定已知解 | 三对角、二维 Poisson，x 随索引变化且正负交替 | eta≤1e-12；良态样例相对解误差≤1e-10 |
| 排序方向 | 非自逆置换的小图 | q/pinv 互逆，PAPᵀ 和 Pb 独立核对 |
| 高度图 | 中心编号最高的 1026 节点星图 | RCM 输出含每个节点且仅一次，无越界/遗漏 |
| 不连通图 | 多个不同大小块和孤立点 | 所有节点编号完整，解和块独立求解一致 |
| 输入规范化 | 同一坐标拆为多项、乱序 | 与合并排序后的矩阵和解一致 |
| 非正定 | [[1,2],[2,1]]、[[1,1],[1,1]] | 清晰失败，无伪成功和输入破坏 |
| 非法数据 | NaN/Inf、负尺寸、非单调 p、越界 i、尺寸溢出 | 在解引用非法位置前拒绝 |
| 因子重用 | 一个 A、至少三个不同 RHS | 每次正确，因子内容不被求解改变 |
| 文件异常 | 缺文件、短文件、错误索引、无法输出 | 非零状态且不伪造解 |

小矩阵需由独立稠密计算检查 `||PAPᵀ-LLᵀ||∞/||A||∞≤1e-12`；阈值针对本组良态 double 样例。病态测试单独报告条件与后向误差，不硬套前向误差阈值。所有成功结果先检查 finite，避免 NaN 绕过比较。

构建先修复 `make test` 的依赖与退出码，再运行新回归。可用工具链支持时使用 AddressSanitizer/UndefinedBehaviorSanitizer 检查高风险输入；未实际运行的检查不能登记为完成。

## 后续里程碑

1. **M0 文档基线**：关键流程、688 文件清单、风险及续接记录。本轮完成；不是全函数语义恢复。
2. **M1 SPD 核心**：完成上述契约和测试，给出可复现命令及误差报告。
3. **M2 排序恢复**：已实现真实动态最小度和递归嵌套剖分，验证消元填充、分隔集、排列合法性，并比较 nnz(L)、时间和结构统计；不宣称复现私有容器布局或对所有矩阵最优。
4. **M3 块结构与超节点**：逐字段建立分配者/读取者/释放者证据；实现块更新并与 M1 因子、残差对比。不可依赖当前截断指针结构。
5. **M4 磁盘分块**：恢复头、索引、数值、版本/端序及生命周期；固定小内存预算下与 M1 比较，测试短读写与清理。
6. **M5 原版兼容**：有原始可执行程序和真实样本后，分别验收文件、API 和数值行为。再决定部分分解、一般矩阵和并行范围。

每一阶段均先补算法证据和不变量，再写失败测试、实现、验证、更新映射与续接记录。不能用同名 wrapper 数量作为进度。
