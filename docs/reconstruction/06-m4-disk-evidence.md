# M4 磁盘分块：证据、格式与验收

日期：2026-09-09。基线：`d7b2db5`，分支：`codex/m4-disk-blocks`。

## 证据与实现边界

| 原符号（reference/funcs） | 可确认的行为 | 新实现与验证 |
|---|---|---|
| `writeFactorChunk_vsdlss` | 写 chunk 标识、块标识、整数索引向量和 double 数值向量；记录 `ftell` 偏移；检查 `fwrite` 返回数量 | `vsdlss_factorize_m4` 写列块及偏移目录；内核限制文件长度测试强制短写 |
| `readFactorChunk_vsdlss` | 检查 chunk/块标识，按偏移定位，检查 `fread` 数量后恢复索引和数值 | `metadata` 核对格式及目录；`record_read` 逐条读取；短头、短数值、错误索引及尾随字节测试 |
| `newFactorBlockHeader_vsdlss` | 分配标量头及索引/数值指针向量 | `vsdlss_m4_factor` 仅驻留置换、列偏移、列长度和文件句柄，不保存指针到磁盘 |
| `forwardSolveBlocked_vsdlss` | 按块顺序做 SAXPY 更新和对角除法 | `vsdlss_m4_solve` 顺序读取稀疏列块执行前代 |
| `backwardSolveBlocked_vsdlss` | 逆序处理块，内积并除对角 | 同一文件逆序定位列块执行回代 |
| `removeAllChunkFiles_vsdlss` | 按所有权删除因子及矩阵 chunk 文件 | 独占 `mkstemp` 后立即 `unlink`，成功/失败关闭句柄，进程退出也由 OS 回收；目录清理测试 |

反编译写入宽度可确认是 4 字节整数、8 字节浮点数，但未从证据确认原版统一版本字段和跨平台端序协议。因此下面定义**重建格式 v1**，不声称原版文件、ABI、逐行或数值舍入兼容。原版 1-based 带长度向量不直接沿用。

## 重建格式 v1

所有整数以显式 little-endian uint64 编码，数值为 IEEE-754 binary64 位模式的 little-endian 编码。要求 8 字节、53 位尾数、指数上限 1024 的 double；使用 POSIX 64 位文件定位。

| 偏移 | 长度 | 内容 |
|---|---:|---|
| 0 | 8 | 魔数 `V S D L S S 4 \\0`（十六进制 `56 53 44 4c 53 53 34 00`） |
| 8 | 8 | 版本 1 |
| 16 | 8 | 端序标记 `0x0102030405060708` |
| 24 | 8 | 维数 n |
| 32 | 8 | 稀疏记录宽度 16 |
| 40 | 8 | 完成标记 1，全部数值成功后才发布 |
| 48 | 24n | 每列依次存 `q[new]=old`、绝对字节偏移、记录数 |
| 48+24n | 可变 | 每个稀疏列块：若干 `(row:uint64, value:binary64)` 记录 |

每列首记录必须是正对角，后续行号严格递增且小于 n。显式零不保存。求解前逐字段核对磁盘头/目录与驻留元数据，并要求文件长度准确；读取时拒绝非有限数值和非法索引。无校验和，不能检测所有有限数值位翻转；文件只在当前因子生命周期内私有使用，没有持久导出/重新打开 API。

## 数学与预算

采用稀疏左看式 Cholesky：工作向量载入 `PAP^T` 当前列，读取已经写好的列 k，找到 `L[j,k]` 后流式执行 `w[i] -= L[i,k]*L[j,k]`，验证并开方主元，将非零列写入磁盘。不调用 M1 的内存数值分解，不在完成内存分解后才导出。各列作为最小磁盘块；目前使用单记录 I/O，未接入 M3 的多列超节点内核。

`budget` 约束 M4 数值阶段的显式堆工作区和驻留因子元数据：`sizeof(vsdlss_m4_factor)+128+40*n` 字节。40n 包含 q、pinv、offset、count、work 五个 8n 数组，128 为固定余量。求解仅保留 q/offset/count 和一个工作向量，低于该上限。不足返回 `VSDLSS_ERR_OOM`；通过 `vsdlss_m4_workspace_bytes` 查询保守需求。

预算**不是进程 RSS 上限**：调用方输入/输出、规范化矩阵、排序阶段、临时路径、libc FILE/分配器和调用栈不计入。规范化矩阵在数值阶段仍驻留。总内存为 O(nnz(A)+n) 加排序开销，不随 nnz(L) 增长；完整输入流式化和排序内存预算尚未实现。

当前优先可验证的磁盘数值闭环。每列扫描规范化矩阵和此前因子列，I/O 较多；尚无页缓存、自适应多列块、异步 I/O 或性能等价承诺。后续优化可加入列依赖索引和有上限的块缓存。

## 生命周期与失败契约

- 输出因子先清空，仅在数值及最终元数据写入成功后交付。
- 临时目录由调用方指定（默认 `/tmp`），独占创建且立即移除目录项。不会覆盖其他文件；失败释放数组并关闭句柄。
- 一个因子支持顺序多 RHS、原地求解；先在工作向量计算，全部成功才覆盖输出。
- 非正定、非有限运算、预算不足和文件错误分别返回状态；损坏的私有文件返回 I/O 错误。
- 对同一个因子不承诺并发安全。不提供崩溃后恢复或跨进程复用。

## 测试

`test/test_m4.c` 独立构造 100 阶网格 SPD 和稠密参考矩阵，在 8192 字节预算下覆盖五种 order 值。验证文件大于预算、独立 `PAP^T=LL^T` 重构、与 M1 和已知非恒定解比较、三个 RHS 原地重用及后向误差。另覆盖重复/乱序输入、不连通分量、单点、预算边界、非法维数、NaN/Inf、非正定、无效目录、头/数值截断、版本/目录/索引损坏、尾随数据、临时文件生命周期。子进程使用 `RLIMIT_FSIZE` 和忽略 `SIGXFSZ` 注入真实短写，不改变生产接口。

复现命令：

```sh
make clean
make CFLAGS='-O2 -Wall -Wextra -Werror -Iinclude -std=c11' test
make sanitizers
```

M3、M4 均纳入默认 `make test` 和 sanitizer 门禁。完整运行结果记录在 `CONTINUATION.md`。
