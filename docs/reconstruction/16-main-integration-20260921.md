保留：精确最小度选择的已消元标记/缓存度数；商图 AMD（order=5）；并行符号映射及单调游标；分块面板更新与前后代内存复用；M3 多 RHS 暂存优化；每面板一个任务的左视数值 DAG；相应回归测试和基准工具。

排除：宽松超节点合并原型。在未经修正的分支上，严格编译后的完整回归出现 M3 面板结构断言失败和 M4 稀疏数值分解失败。恢复基线严格超节点判定，同时保留符号映射优化。主线无 VSDLSS_SN_STRICT 开关。补充空外部行情况下的线程数下界和空行数组指针保护。

## 同机对照

`test/bench_sn.c`，14×14×14 单连通分量网格，2744 节点，4 RHS。相同 benchmark 源码分别链接基线和整合实现，O2，OpenMP，预热一次、重复三次取最小耗时；各进程顺序执行。表中 DAG=0，单位 ms。

| 实现/排序 | 分解 1 线程 | 分解 2 线程 | 单 RHS 1 线程 | 4 RHS 1 线程 | 最大解误差 |
|---|---:|---:|---:|---:|---:|
| 基线 MLD | 134.307 | 121.695 | 0.525 | 1.598 | 3.331e-15 |
| 整合 MLD | 81.921 | 72.090 | 0.578 | 1.602 | 3.331e-15 |
| 整合 AMD | 17.953 | 15.602 | 0.305 | 1.075 | 3.109e-15 |

同排序分解约加速 1.64–1.69 倍；AMD 相对旧默认约 7.48–7.80 倍，但包含排序改变的收益。MLD 的单 RHS 求解略慢，多 RHS 单线程基本持平。仅一个合成矩阵，不能外推真实矩阵或宣称普遍并行加速。DAG 完整数据也保留，当前案例不支持默认启用。

原始数据：[基线](20260921-opt-base.tsv)、[整合 MLD](20260921-opt-new-0.tsv)、[整合 AMD](20260921-opt-new-5.tsv)。

复现：

```sh
make bench_sn
./bench_sn 14 2 4 0
./bench_sn 14 2 4 5
```

CLI 使用 AMD：`./vsdlss_solver --m3 -p 5 --threads 2 job`。已有 API 的 order 参数选择 5；见 [接入文档](../user/QUICKSTART.md)。
