# Full Deterministic MLD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the BFS-only MLD partitioner with a verified deterministic weighted multilevel nested-dissection implementation.

**Architecture:** A focused weighted hierarchy module owns SHEM and coarse graphs; a partition module owns region growth, FM, projection and vertex cover; the existing MLD module owns recursion and fallback. Public ordering behavior stays unchanged.

**Tech Stack:** C11, existing CSC/graph APIs, Make, dependency-free test executables.

**Spec:** `docs/superpowers/specs/2026-09-08-full-mld-design.md`

## Global Constraints

- Preserve `q[new] = old`, deterministic tie-breaking, caller-owned input, and selector values 0 through 4.
- Use no external partitioning library and no recovered proprietary data layout.
- Leaf threshold is 32; contraction stop is 15 percent; density stop is 0.20; balance bound is 7/8.
- Every production behavior is introduced by a failing real-code test.
- Strict C11 compilation and sanitizer verification are required.
