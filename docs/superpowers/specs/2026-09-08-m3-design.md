# M3 已确认设计：低度消元、独立分量与超节点

## 范围与约束

用户已确认独立 M3 入口，M1 不变。输入仍为双精度实对称正定矩阵、上三角 CSC，索引使用 int64_t/csi。不支持本阶段的一般不定 MNA、主元交换、并行、外存、近似丢弃或放宽超节点合并。

新增不透明 `vsdlss_m3_factor`，公开 `vsdlss_factorize_m3(A, order, out)`、`vsdlss_m3_solve(factor, rhs, solution)`、`vsdlss_m3_factor_free(factor)`。order 保持 0..4 的含义，仅选择核心图排序。因子化不依赖 RHS；因子不可变，每次 solve 独立分配工作区。构造失败 out=NULL；求解失败不写调用者 solution；允许 rhs==solution。

## 流水线

规范化 → 原图连通分量 → 每分量动态度 0/1/2/3 消元 → 核心排序 → 符号结构和严格超节点 → 实际块 Cholesky → RHS 约化 → 核心块前回代 → 逆序恢复 → 原编号合并。

完全无耦合的分量直接独立求解。共享分隔器的子域不可当作独立方程组：其贡献仍经块更新累加，不新增域分解接口。结构保守保留消元填充边，即使数值恰好抵消也不按近零阈值删边。

## 低度消元

按当前结构度选择最小度、同度按原编号确定；新填充边同步更新邻居度并重新入队。记录 v、degree、neighbor[3]、pivot d、multiplier[3]=a_i/d。

矩阵更新 A_ij -= a_i*a_j/d，覆盖对角与每个无序邻居对。RHS 按正序更新 b_i -= multiplier_i*b_v，保存当时 b_v；恢复 x_v=b_v/d-sum(multiplier_i*x_i)。度零记录合法，核心为空合法。不要求初始或中间 b_v 为零。

主元<=0返回 NOT_POSDEF；非有限中间值返回 NONFINITE；尺寸溢出或分配失败返回 OOM。极小正主元不自动钳制或加对角扰动。

## 超节点

从核心排列后的符号 L 合并严格相邻列：parent[j]=j+1 且 pattern(L[:,j]) 去掉首行后等于 pattern(L[:,j+1])。节点 J 存列区间、外部行 R、列主序面板和依赖散射映射。

实际计算 L_JJ=chol(F_JJ)，L_RJ=F_RJ*inverse(L_JJ^T)，并将 -L_RJ*L_RJ^T 散射到后续面板。禁止用 M1 数值因子重新打包来冒充块分解；允许复用已验证符号例程。禁止全局 n*n 稠密工作区；面板临时区及更新范围有明确边界。

## 所有权与证据

顶层拥有规范化矩阵、分量映射及分量数组；分量拥有原编号向量、消元记录、核心矩阵、排列、超节点与数值面板；所有 borrowed 指针均注明生命周期，不单独释放。逐字段登记原版偏移、宽度、分配/写入/读取/释放者及可信度。原版偏移不是新结构 ABI，不允许指针转窄整数。

低度数值证据优先核查 factorDeg1Deg2Pf、factorDeg3Pf；minDegreeOrder123Only 属于排序证据；factorWithinBlockExt1To3 的名称不能当作低度预消元证据。

## 验收

手算 Schur 更新、非零 RHS、逆序恢复；交错编号非连通图；全消元和保留核心；同核心同排列 M1/块因子比较；原矩阵残差比较；重复 RHS；失败事务；严格编译、ASan/UBSan。well-conditioned fixtures 的相对因子重构误差、后向误差均<=1e-12，解相对误差<=1e-11。不同排列不逐项比较因子，不规定所有矩阵更快或填充更少。
